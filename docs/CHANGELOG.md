# 0.2.0（历史）

新增加成，n为每枚戒指自己的等级：

- 所有技能检定+n。没有额外增加无技能的裸属性检定或死亡豁免。
- 先攻+floor(n/4)。此项与敏捷提升带来的原版先攻收益叠加。
- 每回合移动距离+n米。
- 暴击门槛降低floor(n/10)。按用户公式传入，不增加自定义最低门槛；极高等级由引擎决定实际有效边界。它不保证每次攻击命中，也不保证所有伤害都能暴击。
- 每回合完整动作+floor(n/5)，附赠动作+floor(n/4)。不是增加“每个动作的攻击次数”；原有Extra Attack、职业和难度规则仍由游戏处理。

双戒指的以上取整项目**分别向下取整后相加**。例如n=3与n=3没有额外动作/附赠动作，n=9与n=10合计额外动作+3、附赠动作+4、先攻+4、暴击门槛降低1，移动+19米。

扩展资源消耗保护到动作、附赠动作、移动距离。升级或重戴时不主动补满当前回合资源，新增上限从下个正常回合补充；法术位仍按原来的休息规则补充。只处理这五类已核对UUID的资源，不修改其他职业资源。

保留模块UUID、物品模板UUID、成长UserVar和Schema。保留旧版Boost Source名称，以便精确删除0.1.0已登记的旧字符串；载入后替换成新版加成，成长不重置。已测试模拟旧版加成记录的替换；真实游戏升级仍未实测。

物品卡静态效果说明更新；**没有新增实时等级/进度界面**，既有“查看生长之戒”动作和控制台保持原行为。界面可行性讨论见UI_FEASIBILITY.md。
